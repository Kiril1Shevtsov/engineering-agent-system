# Engineering Agent System

## Автоматизация работы инженера-проектировщика

**Разработчик: Кирилл Шевцов.**

Агентная система самостоятельно готовит проектную документацию по техническому заданию и исходным планам: выполняет расчёты, формирует чертежи и спецификации, выпускает редактируемые **DWG**, таблицы **XLSX** и комплект **PDF**. Она автоматизирует повседневную работу инженера-проектировщика по подготовке этих материалов.

Я разработал полную агентную систему и собственный **MCP-сервер**, через который агенты работают с инженерными инструментами. Агенты выполняют последовательность проектных задач, создают файлы, проверяют результаты и вносят исправления.

## Что получает заказчик

| Подготовленный материал | Формат |
|---|---|
| Редактируемые чертежи | DWG |
| Расчёты и спецификации | XLSX |
| Комплект документации для просмотра | PDF |

Результат можно открыть в профильных программах, проверить и доработать, не перенося данные из текстового ответа вручную.

## Реальный проект для компании «Вектор»

Система применена при выполнении заказа строительной компании **«Вектор»**, специализирующейся на системах пожарной безопасности. Задача — подготовка документации по пожарной сигнализации и системе оповещения для объекта на **105 помещений и 5 уровней**.

| Этап | Результат |
|---|---|
| Автономная подготовка первой версии | **2,5 часа без ручного вмешательства** |
| Ручные и автоматические корректировки | **Ещё 1,5–2 часа** |
| Подготовленный комплект | **2 файла DWG, 18 страниц PDF и расчётные таблицы** |
| Проверка структуры чертежей | AutoCAD 2027 AUDIT: **0 ошибок структуры DWG** |

Эти результаты получены на конкретном заказе. Готовые инженерные решения требуют профильной проверки; проверка структуры DWG её не заменяет.

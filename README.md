# Engineering Agent System

### Агентная система подготовки инженерной документации

**Кирилл Шевцов — разработка агентной системы и собственного MCP-сервера для связи AI-агентов с инженерными инструментами.**

Система организует работу от технического задания и исходных инженерных материалов до чертежей, расчётов и спецификаций. Результат — редактируемые **DWG**, таблицы **XLSX** и комплект **PDF** для дальнейшей проверки и доработки инженером.

Это публичное описание проекта и демонстрационного применения. Исходный код, внутренние инструкции, исходные чертежи и идентифицирующие данные объекта не публикуются.

## Что разработано

- **Агентная система:** координация этапов подготовки документации, проверки результатов и внесения исправлений.
- **Собственный MCP-сервер:** связующее звено между агентами и инженерными инструментами.
- **Работа с инженерными результатами:** подготовка чертежей, расчётов, спецификаций и выпуск редактируемых файлов, а не только текстовых рекомендаций.

## Рабочий процесс

```text
Техническое задание + исходные инженерные материалы
                         ↓
                  Агентная система
                         ↕
               Собственный MCP-сервер
                         ↕
                Инженерные инструменты
                         ↓
           DWG · XLSX · PDF → проверка инженером
```

Ценность подхода — сокращение ручной подготовки согласованного комплекта материалов и сохранение возможности редактировать результат в профильных инструментах.

## Демонстрационный кейс: пожарная сигнализация и оповещение

| Параметр | Результат |
|---|---|
| Масштаб | 105 помещений, 5 уровней |
| Первая версия | Около 2,5 часа без ручного вмешательства |
| Последующие исправления | Ещё 1,5–2 часа ручных и автоматических корректировок |
| Выходные материалы | 2 файла DWG, 18 страниц PDF, расчётные таблицы |
| Проверка структуры DWG | AutoCAD 2027 AUDIT: 0 ошибок структуры файла |

Показатели относятся к этому кейсу, а не являются универсальной оценкой скорости для любых исходных данных или инженерных разделов.

## Границы результата

Проверка `AUDIT` подтверждает состояние структуры DWG, **но не правильность инженерных решений и не соответствие нормативным требованиям**. Демонстрационный комплект не имеет статуса утверждённой инженером документации. Перед практическим применением необходима профильная инженерная проверка.
